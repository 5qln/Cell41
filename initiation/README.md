# Initiation — the session skills (mirrored from ~/.dsh/skills/)

These skills re-arm a fresh session as the bridge. They live in
`~/.dsh/skills/` on the host (where DSH loads them); this directory mirrors them
into the repo so the initiation itself travels with Cell41 and is reviewable,
versioned, and never lost with a host.

- `fractal-bridge-herdr.md` — the bridge: role, platform basics, the map, the run
  loop, the wrong lakes, the workflow, the lessons, the current state.
- `cell-run.md` — the thin one-command trigger: verify → run
  `granular_conductor.py --max-depth 2` → read B″/∞0′ → report + checklist.
- `5qln-importation.md` — the sealed 5QLN grammar held as operating context.
- `scope-ignited-memory.md` — the scope-ignited formation trail from Hindsight canon.

**Rule:** after every session, update `fractal-bridge-herdr.md`'s "Current state"
and "Where everything is", then re-copy it here so the two never drift. When a
new skill is added, mirror it here and list it above.
