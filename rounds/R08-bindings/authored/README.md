# R08 · the bindings — the authored pack (working handle; the round's name is his to name)

This round binds the attested seam (`cellctl`, R07 canon `992b775`) to its two callers — the
conductor S and the human — and reconciles the enforcement suite's three findings. The seam is
**not** re-built; nothing here imports the engine directly; every soft-layer reach is one
subprocess to `cellctl` (C7). The orchestration *method* is data the engine reads (the bricks);
the binding layer is a baseplate of independent studs (C8).

| deliverable | directory | the one-paragraph shape |
|---|---|---|
| the conductor binding | `pi-cell/` | a pi extension package: 13 slash tools, each one `cellctl` call; the tool table is DATA, the runtime is one shared module (`src/cellctl.mjs` — also what the fixture probe executes) |
| the human binding | `human-binding/` | a manifest addendum: 8 conduction actions, each `command` = `cellctl` + one subcommand, argv-only, no TTY guard; `plant`/`attest` unchanged |
| the enforcement reconciliation | `enforcement/` | the three findings re-pointed (the socket client reduced, the spawn line fenced *deferred — D1*, the ledger through the pinned contract) + the census data extension |
| the podium re-point | `podium/` | a read-only renderer over `state/trail.jsonl` (one `cellctl trail` call per refresh) + the pane manifest re-point (content only — H-R08-6) |
| the bricks | `bricks/` | the C8 method-as-data: `word.json` + `spec.json` + (absent) `soft.json`, each validated by the engine's own readers, never parsed by the binding |
| the author's suite | `selftest.py` | hypotheses only — every test names its criterion and lens; never results, never claims |
| the phase card | `phase-card.md` | predictions + the D14 divergence log + the design rationale |
| the fixtures | `fixtures/` | the commission's fixture list (see `fixtures/README.md`) |

Run the author's suite: `python3 selftest.py` (needs `node` for the probe; the pinned seam is
read from its canonical R07 path). Nothing in this pack was run against the live box: every
engine turn goes to the pinned fixture desk harness on its own socket (H-R08-1), and the live
ledger/trail are never written.
